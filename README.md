# psst

### Talk like nobody's listening. Because nobody is.

## 👉 [**Try it now**](https://srvstav.github.io/psst/) — open it in two tabs.

No account. No phone number. Just a secret phrase you share.

- 🔒 **Only you two can read it.** Not the server. Not us. Not anyone.
- 🤫 **Whisper** and it disappears after it's read.
- 🧩 **Lock a message with a riddle.** Wrong 5 times? Gone forever.
- ⏳ **Send a message to the future.** It opens when you say.
- 📦 **Send huge files.** Any size.

---

**Run your own:** `npm install && npm start` → http://localhost:8080
